Ziel: WCAG 2.1 AA. Prüfung via https://wave.webaim.org/report#/share.erfindergeist.org

## Checkliste (behobene Fehler)

| # | Datei | Problem | Status |
|---|-------|---------|--------|
| 1 | `assets/templates/tab-galerie.php` | `<img id="gallery-lb-img">` hatte leeres `alt` im statischen HTML (WAVE sieht HTML vor JS) | Behoben: `aria-hidden="true"` initial; JS setzt `alt = caption \|\| name` + entfernt `aria-hidden` |
| 2 | `assets/templates/tab-downloads.php` | 5x `<th></th>` leer (Wiki/Raw/Cloud/Beitrag/Download-Spalten) | Behoben: `<th><span class="visually-hidden">...</span></th>` |
| 3 | `assets/templates/tab-galerie.php` | `role="menu"` auf Share-Panel ohne `role="menuitem"` Kinder | Behoben: `role="group" aria-label="Teilen"` |
| 4 | `index.php` | Keine `<h1>` auf der Seite | Behoben: `<h1 class="visually-hidden">Share - Erfindergeist Jülich</h1>` in `<main>` |
| 5 | `index.php` | `<nav class="eg-nav">` ohne `aria-label` (Seite hat mehrere Navs) | Behoben: `aria-label="Hauptnavigation"` |
| 6 | `index.php` | `<ul role="tablist">` ohne `aria-label` | Behoben: `aria-label="Seitenbereiche"` |
| 7 | `assets/templates/tab-galerie.php` | `<span id="gallery-lb-counter">` per JS befüllt, kein `aria-live` | Behoben: `role="status"` |
| 8 | `assets/templates/tab-galerie.php` | Caption nicht mit Lightbox-Bild verknüpft | Behoben: `aria-describedby="gallery-lb-caption"` auf `<img>` |
| 9 | `assets/templates/tab-galerie.php` | `aria-label="Nachstes Bild"` - fehlendes Umlaut | Behoben: `aria-label="Nächstes Bild"` |
