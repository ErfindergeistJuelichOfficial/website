Explain + Info Cards

.explain-card (section-plugin.css)

Was ist eine REST API?

Eine REST API ist wie ein Kellner im Restaurant: Du gibst deine Bestellung auf (Request), der Kellner geht in die Kuche (Server) und bringt dein Essen zuruck (Response).
